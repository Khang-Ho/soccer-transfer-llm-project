# soccer-transfer-llm-project

## Research Question

Does the structure of training data affect an LLM's ability
to recall factual information about soccer player transfers?

## Goal

This project investigates whether different representations
of the same soccer transfer information affect the model's
ability to recall factual information.

## Experiments

- Baseline model
- Different data structures representation
- Recall evaluation

## Independent variable
Data structures

## Dependent variable
Recall performance

## Future Application
If the trained model demonstrates reliable factual recall, the project may be extended into an interactive assistant for European soccer transfer information. Users would be able to aske questions about players, clubs, transfer fees, and transfer histories through a web interface.
